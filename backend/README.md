# HisabKhata Backend Service (Phase 01 Scaffold)

This directory serves as the isolated backend scaffold for HisabKhata.

## Scope Rules
- **Phase 01 (Current)**: Minimal scaffold only. No database connection, no auth tokens, no customer or sales endpoints.
- **Phase 02 (Planned)**: MongoDB connection (Mongoose/native client), User/Store auth schemas, Product & Inventory collections, Sales & Due Ledger models.
- **Phase 03 (Planned)**: Ledger aggregations, daily/weekly/monthly statements, PDF generation service.
